# Linear Algebra, Visualized

Animated explanations of linear algebra, made with [Manim](https://www.manim.community/)
(the Python library behind 3Blue1Brown's videos), plus a short LaTeX report.

Instead of only reading proofs, each topic is turned into a short animation:
planes fanning out to form a span, a grid collapsing onto a line under a linear map,
one vector measured with two different bases, and more.
